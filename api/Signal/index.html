Signal

An ordered linked collection of asynchronous listeners. Signals are created with Echo.new<T...>(); the same type pack is used by subscriptions, dispatch, and waiting.

fire traverses from the oldest connection to the newest and resumes each connected callback through task.spawn. Traversal order is defined, but callback completion order and return values are not part of the contract.

Appends a listener that disconnects before its first invocation. The disconnect-before-callback order prevents nested fires from invoking the one-shot listener twice.

wait​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
Signal:wait() → ...any

Yields the calling coroutine until the next dispatch and returns all fired arguments. There is no built-in timeout. Clearing or destroying the Signal disconnects the hidden one-shot subscription without resuming the waiter.

fire​

</>
Signal:fire(
...: any--

Values forwarded unchanged to each scheduled callback.

) → ()

Traverses connected listeners and resumes callbacks through task.spawn. The method does not explicitly yield, await completion, collect callback returns, or clone table payloads. A callback may begin before fire returns.

disconnectAll​

</>
Signal:disconnectAll() → ()

Disconnects every active listener, updates each public handle, clears node references, and leaves the Signal reusable for a new listener generation.

destroy​

</>
Signal:destroy() → ()

Exact runtime alias of disconnectAll. Use it to communicate terminal owner intent, but note that Echo does not enforce a destroyed state or reject later connections and fires.
